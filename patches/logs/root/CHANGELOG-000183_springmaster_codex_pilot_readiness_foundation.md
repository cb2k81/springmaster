# 000183 springmaster codex pilot readiness foundation

## Scope

Springmaster-only governance, tooling, contracts, tests and reference input for the controlled Codex pilot.

## Summary

- Accept ADR-0015 and activate dedicated AI Agent Development Governance without promoting unrelated draft governance to strict enforcement.
- Freeze a traceable Business Partner dummy Fachkonzept and a machine-readable pilot acceptance contract.
- Add a closed agent task schema, external-root contract and detached-worktree harness with no Codex invocation or Git integration operation.
- Add a strict, read-only `codex-pilot-readiness-v1` gate plus positive, finding and tool-error fixtures.
- Register strict pilot rules, the readiness gate, tests, fixtures, documentation scope and runtime artifact paths.
- Close the Project Directory contract gap for the activated `.cocondo` toolkit tree and its extensionless launchers.
- Exclude operator diagnostics and chat-upload work areas from Git and exports.
- Advance Springmaster to `0.19.0-foundation`, Tooling to `0.9.0` and the state patch to this delivery.
